## C. 本机 ffmpeg 出片（数字人 L2 主链路）

1. 新建目录，放入：
   - `acceptance-samples/sub.srt`
   - `acceptance-samples/make-digital.sh`（或 `.bat`）
   - 素材三件（**改名为脚本内所写**）：`口播-正面.mp4`（任意竖屏人像视频 ≥10s）、`配音.wav`（任意音频）、`分镜1.png`（任意图片）
     - 没有素材就用手机随手录 10 秒口播 + 一张截图 + 微信语音转 wav
2. 执行：`bash make-digital.sh`（Windows 双击 `.bat`）
3. **预期**：产出 `digital-out.mp4`
   - 画面：人像循环铺满、竖屏裁切
   - 0-15s 左右起有中文字幕（白字黑边）
   - 中段（约第 2 段窗口）切入 `分镜1.png` 副画面
   - 时长≈30s，有配音声
4. 常见问题：
   - `Unable to load font` → 改脚本里 `SRT_STYLE` 的 `FontName` 为本机存在的字体
   - `No such filter: subtitles` → ffmpeg 编译不带 libass，换官方完整包
   - 素材分辨率差异大 → 形象模式会强制裁 9:16；分镜模式要求编码一致（脚本头注释已写）

> 沙箱无 ffmpeg，**此组只有你能验**。出片成功 = L2 链路闭环。

## D. 服务端链路（可选，10 分钟）

### D-1 IM 远程指令网关
```bash
cd ai-super-employee/im-bot-gateway
ADMIN_SECRET=你的密钥 PORT=8788 node src/server.mjs
# 另开终端：
curl -s localhost:8788/health
curl -s -X POST localhost:8788/api/command -H 'content-type: application/json' \
  -H 'x-admin-secret: 你的密钥' -d '{"text":"生成周报","source":"http"}'
curl -s -H 'x-admin-secret: 你的密钥' localhost:8788/api/commands
```
预期：health `ok`；入队返回 id；拉取可见 pending 指令；错密钥 403。
控制台「远程指令」页填同一地址+密钥 → 拉取 → 执行（openComposer 预填）。

### D-2 企微客服服务（mock）
```bash
cd ai-super-employee/wecom-kf-service
# config.json 写入：{ "mock": true, "adminSecret": "你的密钥" }
node src/server.mjs
curl -s localhost:8787/health          # {"ok":true,"mock":true,...}
curl -s -X POST localhost:8787/api/broadcast \
  -H 'content-type: application/json' -H 'x-admin-secret: 你的密钥' \
  -d '{"content":"{{name}}你好，本周到店可领体验装","recipients":[{"name":"王总","external_userid":"wm1"},{"name":"无ID","external_userid":""}]}'
```
